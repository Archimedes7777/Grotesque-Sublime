# Bio and link plan: one brand across four handles

**Problem:** your handles differ. Instagram and YouTube are `activelypsychotic`; X is `realbobfrapples`; TikTok is `bobfrapplesgns`. A visitor who finds you on TikTok cannot tell it is the same brand as your Instagram, and anyone can claim `activelypsychotic` on X or TikTok and pose as you.

**Goal:** every profile reads as ActivelyPsychotic, links to the other three, and looks the same at a glance. Nothing here asks for a password; you make every change yourself in each app.

## Step 1: protect the brand handle (do first, about 10 minutes)

| Platform | Action |
|---|---|
| X | Check whether `activelypsychotic` is free. If it is, decide: rename `realbobfrapples` to it (keeps your followers), or register it as a second placeholder account protected with strong MFA |
| TikTok | Same check for `activelypsychotic` |
| Instagram, YouTube | Check whether `bobfrapples` is free; claim it as a placeholder that points to the main account if you want the universe name protected too |

**Recommendation:** rename where you can rather than run extra accounts. Each extra account is one more login to secure. Renaming usually keeps followers, but old links and mentions of the old handle may stop working, and some platforms limit how often you can rename **[Unverified: check each app's current rules before renaming]**. Do renames in a quiet week, not during the Halloween posts.

## Step 2: matching display names

Use the same display name everywhere: **ActivelyPsychotic**. Add the universe name only where space allows, for example "ActivelyPsychotic | Bob Frapples".

## Step 3: bios (drafts; keep each within the platform's limit)

Shared core line: "Dark satirical AI art. The Bob Frapples Universe."

| Platform | Draft bio |
|---|---|
| Instagram | "Dark satirical AI art.\nThe Bob Frapples Universe.\nAI-assisted, human-edited.\nNew piece every few days." |
| TikTok | "Dark satirical AI art. The Bob Frapples Universe. Process videos here." |
| YouTube | "ActivelyPsychotic makes dark, satirical, surreal art with AI tools and human editing. This channel has Shorts of each piece and longer films showing how they are made. Part of the Bob Frapples Universe." |
| X | "Dark satirical AI art. The Bob Frapples Universe. Same art on Instagram and YouTube: activelypsychotic" |

"AI-assisted, human-edited" is a truthful disclosure. Keep it only if it stays true.

## Step 4: linking the four accounts

- **Profile link field:** until a shop or website exists, use a single link page that lists all four accounts. If you use a link-in-bio service, give it its own strong password and MFA; it controls where every visitor goes. Alternatively, point `activelypsychotic.com` at a simple page you control **[later, once the domain is set up]**.
- **Instagram:** add your other profiles in the profile's links section if offered **[Unverified: menu names change]**.
- **YouTube:** add links to Instagram, TikTok, and X in Customization > Basic info > Links **[Unverified]**.
- **TikTok and X:** one link field each; use the link page.

## Safety notes

- Renaming is a common moment for phishing. Ignore any message that offers to "verify" or "reserve" a handle; change handles only inside each official app.
- After any rename, update the handles table in `.agents/product-marketing.md` and the knockout checklist.
