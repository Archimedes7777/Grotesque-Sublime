# USPTO knockout search checklist (phone friendly)

A knockout search is a free first check for obvious conflicts before you spend money. It is **not** a clearance opinion and not legal advice. Plan about 1 to 2 hours. Do it in a mobile browser; request the desktop site if the search page is cramped.

Search page: `tmsearch.uspto.gov` (the USPTO's trademark search tool) **[Moderate]**. Menu names change; if something looks different, search the USPTO site for "trademark search" and adjust.

## Before you start

- [ ] Open a notes app. Paste the results table (bottom of this page) into it.
- [ ] Plan to **screenshot each results page with the date visible**. This is your clearance record.
- [ ] Do not type any personal details into the USPTO search. It does not need them.

## Part 1: exact and sound-alike word searches

Use the plain word search. Set the status filter to **Live** (pending and registered) for the first pass, then repeat once with **Dead** to understand history. If the box accepts a wildcard, `*` may widen a search **[Unverified]**. Type each string exactly.

| 6 | `ACTIVLY PSYCHOTIC` | Common misspelling |

For each result: tap it and note the **serial number, owner, status, goods and services, and class**. A result only matters if it is live or pending **and** covers goods that could overlap yours.

## Part 3: the logo (design search)

The skull-in-apple mark is the higher-risk asset because Apple Inc. opposes many bitten-apple marks.

1. Open the USPTO's design search code manual and look up the codes for **apples** and **skulls** **[Unverified]**: I did not confirm the exact code numbers, so do not type numbers from memory.
2. Search each code, then both together, with the status filter on **Live**.
3. Note any apple mark with a bite, leaf, or similar silhouette in classes 9, 16, 25, 35, and 41, and any skull-and-fruit marks.
4. Screenshot the results.

## Part 5: how to judge what you found

Two marks can conflict when they look, sound, or mean similar things **and** the goods are related. Ask for each hit:

1. Does it **sound** like mine when said aloud?
2. Does it **look** or **mean** something close?
3. Are the goods in the same or neighboring classes (16, 25, 41, 35)?
4. Is it **live or pending**, not dead?

If the answer to all four is yes or maybe, mark it **High** and take it to an attorney. Dead marks are lower risk but are still worth noting.

## Stop and call an attorney if

- Any live or pending mark sounds like ACTIVELYPSYCHOTIC in classes 16, 25, 41, or 35 (start with `PSYCHO ACTIVE`, serial 97555544)
- Any live apple-with-a-bite design appears in your classes
- An Apple Inc. mark appears in your design results
- You find another seller using your names on goods like yours
